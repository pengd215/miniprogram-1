# 📦 微信小程序：智能仓储物料管理系统 (Smart Warehouse Mini Program)

> **项目状态**：🚧 开发中 (In Progress) - 核心功能已上线，部分模块迭代中

## 📌 项目简介
这是一个基于 **微信小程序原生开发** + **微信云开发 (CloudBase)** 的轻量级仓储管理工具。旨在解决传统仓库管理中纸质记录繁琐、数据不同步的问题，实现物料出入库的数字化与实时化。

本项目由个人加ai完成，目前处于快速迭代阶段。

## 🚀 核心功能 (已实现)
- ✅ **身份鉴权**：基于云函数的用户登录与权限校验（管理员/普通员工/业务员/仓管）。
- ✅ **扫码作业**：调用手机摄像头扫描条码/二维码，快速录入物料信息。
- ✅ **实时库存**：云端数据库实时同步，支持多端数据一致性查看。
- ✅ **出入库记录**：完整的操作日志追踪，支持按时间段筛选历史流水。
- ✅ **敏感配置隔离**：已移除 `project.private.config.json` 等敏感文件，确保仓库安全。

## 🛠 技术栈
- **前端**：微信小程序原生框架 (WXML, WXSS, JS/TS)
- **后端**：微信云开发 (Cloud Functions, Cloud Database, Cloud Storage)
- **版本控制**：Git / GitHub
