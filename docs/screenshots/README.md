- `workbench.png` — 工作台（搜索 / 扫码 / 待办）
- `product-list.png` — 产品列表
- `inbound-outbound.png` — 出入库
- `flow-logs.png` — 流水日志
- `warehouse.png` — 库区 / 库位管理
- `permission.png` — 员工权限
- `client-quote.png` — 客户报价

图片建议统一宽 750px（或 375px@2x），PNG 格式。
