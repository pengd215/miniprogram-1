# 客户端改版 · 需求分析与设计方案（已确认版）

项目：逐鹿减振器库存系统小程序 · 客户端
日期：2026-08-18
状态：**关键决策已确认，待批准第一期实施**

---

## 一、背景与目标

现有客户端只有一个"OE号报价查询"页面（绿色配色），客户登录后直接进入。本次改版目标：

1. 把客户端扩展为 **4 个页面**的完整门户：首页、改装配件、关于我们、个人
2. 底部增加 **4 项导航栏**（需求原文说"三个"但列出 4 项，按 4 项实施）
3. 整体 UI 统一为 **灰、黑、米（米色）** 三色配色，替换现有绿色系
4. 首页保留现有查询能力，增加公司 logo，美化输入框与按钮

## 二、已确认的关键决策

| 编号 | 决策项 | 确认结果 |
|------|--------|----------|
| Q1 | 底部导航方案 | **自制底部导航组件**（不影响员工端原生 tabBar） |
| Q2 | 个人页"用户名"范围 | **仅显示名称**，登录账号不动 |
| Q3 | 改装件数据源 | **新建独立集合**（与普通产品完全隔离） |
| Q4 | 关于我们内容维护 | **写死在代码里**（首期方案，改内容需发版） |
| Q5 | 价格颜色 | 待定，默认保留红色数字，可随时调整为黑色 |

## 三、现状分析（技术底座）

| 项目 | 现状 | 对改版的影响 |
|------|------|------|
| 客户端入口 | 登录页判断 `role === 'customer'` 后跳转 `pages/client/search` | 首页就是查询页，**登录跳转无需改动** |
| 客户账号 | 与员工共用 `employees` 集合（role=customer） | 个人页资料直接读写该集合的客户记录 |
| 报价查询 | 云函数 `clientSearchQuote` + products 集合 watch 实时监听 | 首页保留此逻辑，只改 UI |
| 导航 | 原生 tabBar 全局唯一、最多 5 项，已被员工端 4 项占用 | 客户端 4 页用自制导航组件承载 |
| 图片素材 | `images/zhulu-logo.png` 已存在 | 首页 logo 直接使用 |

## 四、页面需求拆解

### 4.1 首页（现有查询页改版）

- **保留**：OE号/配件名搜索、结果卡片、图片预览、watch 实时同步
- **新增**：顶部品牌区（logo + 公司名）、灰黑米风格搜索框（白底圆角输入框 + 黑色查询按钮）、米色/浅灰页面背景

### 4.2 改装配件页（新页面）

1. **改装类型介绍**：图文区块，介绍改装类目（文案需你提供，首期先用占位文案）
2. **改装产品卡片**：双列卡片流（图、名称、适用车型、参考价）
3. **数据源**：独立集合 `modified_products`，通过新云函数查询，客户端不直连数据库

> ⚠️ 独立集合的影响说明：改装件不走现有 products 集合，因此员工端的建档、入出库、库存、流水、导出功能**均不覆盖改装件**。首期改装件数据通过云开发控制台手工录入；若后续需要员工端管理改装件（上下架、改价），需要单独开发一套管理功能，届时另立需求。

### 4.3 关于我们页（新页面）

- 顶部公司形象图（需你提供照片）
- 公司介绍文字段落（需你提供文案，首期可用占位文案）
- 产品/车间图片九宫格（点击放大预览）
- 联系方式卡片：电话（点击拨打）、微信号（点击复制）

### 4.4 个人页（新页面）

客户资料编辑，三个字段：

| 字段 | 对应数据库字段 | 说明 |
|------|----------------|------|
| 用户名 | `employees.name`（显示名称） | 登录账号 username 不可改 |
| 公司 | `employees.company`（新增） | 首次保存自动写入 |
| 联系方式 | `employees.contact`（新增） | 首次保存自动写入 |

通过新云函数更新（客户端无直接改库权限），保存后同步更新本地缓存。

## 五、UI 设计规范（灰黑米三色）

### 5.1 色板

| 角色 | 色值 | 用途 |
|------|------|------|
| 主黑 | `#1F1F1F` | 主按钮、标题、底部导航选中态 |
| 深灰 | `#4A4A4A` | 正文文字 |
| 中灰 | `#9A9A9A` | 次要文字、占位符 |
| 浅灰 | `#F5F5F4` | 页面背景 |
| 边框灰 | `#E8E5E0` | 卡片描边、分割线 |
| 米色 | `#F7F3EB` | 卡片背景、强调区块 |
| 深米 | `#D9C7A0` | 点缀色（角标、标签描边） |
| 价格红 | `#C0392B` | 价格数字（Q5 待定，可改黑色） |

以 CSS 变量形式定义，后续换主题只改变量。

### 5.2 组件风格约定

- 卡片：白底或米底，圆角 16-24rpx，浅描边代替重阴影
- 按钮：主按钮黑色胶囊形，次按钮米色描边
- 底部导航：白底，选中态黑色图标+文字、未选中灰色
- 字体层级：标题 34-36rpx 加粗 / 正文 28rpx / 辅助 24rpx

## 六、技术方案

### 6.1 自制底部导航组件

新建 `components/client-tabbar`（js/wxml/wxss/json 四件套）：

- fixed 定位在页面底部，白底 + 顶部细描边
- 4 个页签：首页 / 改装配件 / 关于我们 / 个人
- 图标用内联 SVG 绘制（灰色未选中 / 黑色选中），不依赖新图片素材
- 点击切换用 `wx.redirectTo`，当前页签高亮由页面传参控制
- 4 个客户端页面底部预留导航高度占位，避免内容被遮挡

### 6.2 页面注册与路由

app.json 新增 3 个页面（首页复用 `pages/client/search` 改造）：

```
pages/client/parts     改装配件
pages/client/about     关于我们
pages/client/profile   个人中心
```

客户端页面不注册进 tabBar（那是员工端的），登录跳转保持现状。

### 6.3 数据结构变更

| 集合 | 变更 | 说明 |
|------|------|------|
| `modified_products` | **新建** | 字段：name、car_model、price、images、category（改装类型）、desc、create_time |
| `employees` | 客户记录新增 `company`、`contact` | 可选字段，无迁移成本 |
| `products` | 不动 | 普通产品查询完全不受影响 |

### 6.4 新增云函数

| 云函数 | 作用 |
|--------|------|
| `clientModifiedList` | 查询改装产品列表（改装配件页用） |
| `clientUpdateProfile` | 客户更新自己的 name/company/contact（个人页用） |

### 6.5 图片资源策略

- logo 用本地 `images/zhulu-logo.png`
- 公司照片、改装产品图等素材**上传云存储**取 URL 引用，避免小程序包体积超限（主包限 2MB）

## 九、风险提示

1. 客户端 watch 全量监听 products 集合，产品量大后建议首页查询改走云函数分页（本次不动）
2. 改装件独立集合意味着员工端无法管理改装件，首期靠控制台手工录入
3. 自制导航用 redirectTo 切换，页面间不保留滚动位置（查询结果可通过缓存缓解，视体验再定）
