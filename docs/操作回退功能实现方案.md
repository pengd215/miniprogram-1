# 逐鹿减振器库存系统 — 全页面操作回退功能实现方案

> **版本**: v1.0 | **日期**: 2026-08-23 | **适用项目**: zhulu-shock-absorber-inventory

---

## 一、需求背景与目标

### 1.1 业务痛点
员工在日常使用库存系统时，可能出现以下误操作：
- **入库数量填错** → 库存虚高
- **出库数量填错** → 库存不足
- **编辑产品时误改关键字段**（OE码、库存等）
- **误建重复产品档案**
- **库位绑定/解绑操作错误**

当前系统**没有任何回退机制**，一旦操作提交，数据即被永久修改。

### 1.2 设计目标
| 目标 | 说明 |
|------|------|
| ✅ 全页面覆盖 | 入库、出库、产品编辑/创建、仓库管理均支持回退 |
| ✅ 操作级粒度 | 每次提交操作均可独立回退 |
| ✅ 数据一致性 | 回退操作本身也记录在案，可追溯 |
| ✅ 权限控制 | 仅管理员/主管可执行回退，普通员工仅可查看 |
| ✅ 防止连环回退 | 同一操作不可重复回退 |
| ✅ 低侵入性 | 最小化对现有代码的修改 |

---

## 二、技术方案总览

### 2.1 核心机制：操作快照 + 逆向回滚

```
用户执行操作 → [①保存操作前快照] → [②执行原业务逻辑] → [③关联快照ID到流水记录]
                                                                    ↓
管理员点击"撤销" ← [⑤标记快照已回退] ← [④根据快照恢复数据]
```

### 2.2 新增数据库集合：`operation_snapshots`

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `_id` | string | 自动生成 |
| `operation_type` | string | 操作类型：`inbound` / `outbound` / `product_create` / `product_update` / `warehouse_op` |
| `target_collection` | string | 受影响的集合名：`products` / `warehouses` / `locations` |
| `target_doc_id` | string | 受影响文档的 `_id` |
| `snapshot_data` | object | **操作前的完整数据快照**（JSON深拷贝） |
| `operation_payload` | object | 本次操作的输入参数（用于日志展示） |
| `related_log_id` | string | 关联的 `transaction_logs` 记录ID（如有） |
| `operator_openid` | string | 原操作人的 openid |
| `status` | string | `active`(可回退) / `reverted`(已回退) / `expired`(已过期) |
| `create_time` | Date | 快照创建时间（服务器时间） |
| `revert_time` | Date | 回退执行时间（如已回退） |
| `reverted_by` | string | 执行回退的操作人openid |
| `revert_remark` | string | 回退原因备注 |

### 2.3 新增云函数：`undoOperation`

**入口参数**：
```javascript
{
  snapshotId: string,      // 要回退的快照ID
  remark: string           // 回退原因（必填）
}
```

**返回值**：
```javascript
{
  success: true/false,
  message: string,
  revertedType: string     // 回退的操作类型
}
```

## 三、详细实现步骤

### 步骤 1：创建操作快照工具函数

在云函数目录下新建共享模块，供各业务云函数引用：

**文件**: `cloudfunctions/shared/snapshotHelper.js`

```javascript
// cloudfunctions/shared/snapshotHelper.js
// 操作快照工具函数 —— 被各业务云函数 require 使用

const db = require('wx-server-sdk').database();

/**
 * 创建操作前快照
 * @param {Object} transaction - 数据库事务对象（如在事务中调用）或 null
 * @param {Object} params
 * @param {string} params.operationType - 操作类型
 * @param {string} params.targetCollection - 目标集合
 * @param {string} params.targetDocId - 目标文档ID
 * @param {Object} params.payload - 操作参数
 * @param {string} params.operatorOpenId - 操作人
 * @param {string} [params.relatedLogId] - 关联的流水ID
 * @returns {Promise<string>} 快照文档的 _id
 */
async function createSnapshot(transaction, params) {
  const {
    operationType,
    targetCollection,
    targetDocId,
    payload,
    operatorOpenId,
    relatedLogId
  } = params;

  // 读取当前数据作为快照
  const collection = transaction
    ? transaction.collection(targetCollection)
    : db.collection(targetCollection);

  const docRes = await collection.doc(targetDocId).get();
  const snapshotData = docRes.data || null;

  const snapshotRecord = {
    operation_type: operationType,
    target_collection: targetCollection,
    target_doc_id: targetDocId,
    snapshot_data: snapshotData,       // 操作前的完整数据（新增时为null）
    operation_payload: payload || {},
    related_log_id: relatedLogId || '',
    operator_openid: operatorOpenId,
    status: 'active',                  // 可回退状态
    create_time: new Date(),
    revert_time: null,
    reverted_by: null,
    revert_remark: ''
  };

  // 写入快照集合
  const snapCollection = transaction
    ? transaction.collection('operation_snapshots')
    : db.collection('operation_snapshots');

  const result = await snapCollection.add({ data: snapshotRecord });
  return result._id; // 返回快照ID，用于关联到流水记录
}

module.exports = { createSnapshot };
```

> **注意**：微信云开发云函数之间不能直接 `require` 本地文件。有两种解决方案：
> 1. **推荐**：将快照逻辑直接内联到每个需要修改的云函数中（见下方具体实现）
> 2. 或者将 `shared` 目录部署为独立的 npm 包

### 步骤 2：改造入库云函数 — 支持快照

**文件**: `cloudfunctions/submitInbound/index.js`（修改）

```javascript
// cloudfunctions/submitInbound/index.js
const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database();
const _ = db.command;

exports.main = async (event, context) => {
  const wxContext = cloud.getWXContext();
  const currentOpenId = wxContext.OPENID;
  const { productId, quantity, remark } = event;
  const num = parseInt(quantity, 10);

  if (!productId) {
    return { success: false, message: '产品ID缺失' };
  }
  if (isNaN(num) || num <= 0) {
    return { success: false, message: '入库数量必须大于0' };
  }

  try {
    return await db.runTransaction(async transaction => {
      // === 1. 查找产品 ===
      const productDoc = await transaction.collection('products').doc(productId).get();
      if (!productDoc.data) {
        throw new Error('产品不存在');
      }
      const product = productDoc.data;

      // === 2. 【新增】创建操作前快照 ===
      const snapshotResult = await transaction.collection('operation_snapshots').add({
        data: {
          operation_type: 'inbound',
          target_collection: 'products',
          target_doc_id: productId,
          snapshot_data: { ...product },         // 深拷贝入库前完整数据
          operation_payload: { quantity: num, remark: remark || '无备注' },
          related_log_id: '',                     // 等流水写入后回填
          operator_openid: currentOpenId,
          status: 'active',
          create_time: new Date(),
          revert_time: null,
          reverted_by: null,
          revert_remark: ''
        }
      });
      const snapshotId = snapshotResult._id;

      // === 3. 更新库存 ===
      const oldStock = Number(product.stock);
      const safeOldStock = isNaN(oldStock) ? 0 : oldStock;
      const newStock = safeOldStock + num;

      await transaction.collection('products').doc(productId).update({
        data: { stock: newStock }
      });

      // === 4. 记录流水（关联快照ID）===
      const logResult = await transaction.collection('transaction_logs').add({
        data: {
          product_id: productId,
          oe_no: product.oe_no || '',
          kyb_no: product.kyb_no || '',
          model: product.model || '',
          type: 'inbound',
          _openid: currentOpenId,
          quantity: num,
          remark: remark || '无备注',
          snapshot_id: snapshotId,                // 【新增】关联快照
          create_time: db.serverDate()
        }
      });

      // === 5. 【新增】回填流水ID到快照 ===
      await transaction.collection('operation_snapshots').doc(snapshotId).update({
        data: { related_log_id: logResult._id }
      });

      return { success: true, message: '入库成功', snapshotId };
    });
  } catch (err) {
    console.error('入库事务失败:', err);
    return { success: false, message: err.message };
  }
};
```

**改动要点**：
- 在事务中、库存更新**之前**插入快照记录
- 流水记录中新增 `snapshot_id` 字段关联快照
- 流水写入后回填 `related_log_id` 到快照（双向关联）

### 步骤 5：创建核心回退云函数

**文件**: `cloudfunctions/undoOperation/index.js`（新建）⭐ 核心文件

```javascript
// cloudfunctions/undoOperation/index.js
// ==================== 操作回退核心云函数 ====================
// 支持回退的操作类型：
//   - inbound  → 扣减库存（抵消入库）
//   - outbound → 增加库存（抵消出库）
//   - product_update → 恢复产品字段到编辑前
//   - product_create → 删除产品及关联流水（软删除/标记删除）

const cloud = require('wx-server-sdk');
cloud.init({ env: cloud.DYNAMIC_CURRENT_ENV });
const db = cloud.database();
const _ = db.command;

// ========== 权限配置 ==========
// 只有以下角色可以执行回退操作
const UNDO_ALLOWED_ROLES = ['admin', 'warehouse_manager'];

/**
 * 主入口
 */
exports.main = async (event, context) => {
  const wxContext = cloud.getWXContext();
  const currentOpenId = wxContext.OPENID;
  const { snapshotId, remark } = event;

  // ====== 1. 参数校验 ======
  if (!snapshotId) {
    return { success: false, code: 400, message: '缺少快照ID' };
  }
  if (!remark || !remark.trim()) {
    return { success: false, code: 400, message: '请填写回退原因' };
  }

  // ====== 2. 权限校验 ======
  const role = await getUserRole(currentOpenId);
  if (!UNDO_ALLOWED_ROLES.includes(role)) {
    return { success: false, code: 403, message: `权限不足：当前角色[${role}]无法执行回退操作` };
  }

  try {
    // ====== 3. 读取快照 ======
    const snapDoc = await db.collection('operation_snapshots').doc(snapshotId).get();
    if (!snapDoc.data) {
      return { success: false, code: 404, message: '快照记录不存在' };
    }
    const snapshot = snapDoc.data;

    // ====== 4. 状态检查 ======
    if (snapshot.status === 'reverted') {
      return { success: false, code: 409, message: '该操作已被回退，不可重复操作' };
    }
    if (snapshot.status === 'expired') {
      return { success: false, code: 410, message: '该操作已超过回退有效期' };
    }
    if (snapshot.status !== 'active') {
      return { success: false, code: 400, message: `快照状态异常: ${snapshot.status}` };
    }

    // ====== 5. 根据操作类型执行对应回退策略 ======
    let revertResult;
    switch (snapshot.operation_type) {
      case 'inbound':
        revertResult = await revertInbound(snapshot, currentOpenId, remark);
        break;
      case 'outbound':
        revertResult = await revertOutbound(snapshot, currentOpenId, remark);
        break;
      case 'product_update':
        revertResult = await revertProductUpdate(snapshot, currentOpenId, remark);
        break;
      case 'product_create':
        revertResult = await revertProductCreate(snapshot, currentOpenId, remark);
        break;
      default:
        return { success: false, code: 400, message: `不支持回退的操作类型: ${snapshot.operation_type}` };
    }

    // ====== 6. 更新快照状态为"已回退" ======
    await db.collection('operation_snapshots').doc(snapshotId).update({
      data: {
        status: 'reverted',
        revert_time: db.serverDate(),
        reverted_by: currentOpenId,
        revert_remark: remark.trim()
      }
    });

    // ====== 7. 记录回退操作日志 ======
    await db.collection('transaction_logs').add({
      data: {
        type: 'undo',
        product_id: snapshot.target_doc_id,
        oe_no: snapshot.snapshot_data?.oe_no || '',
        quantity: 0,
        remark: `【回退${snapshot.operation_type}】${remark.trim()} | 原操作人: ${snapshot.operator_openid}`,
        _openid: currentOpenId,
        related_undo_snapshot_id: snapshotId,
        create_time: db.serverDate()
      }
    });

    return {
      success: true,
      message: `成功回退${getOperationTypeName(snapshot.operation_type)}操作`,
      revertedType: snapshot.operation_type,
      ...revertResult
    };

  } catch (err) {
    console.error('回退操作失败:', err);
    return { success: false, code: 500, message: err.message || '服务器内部错误' };
  }
};

// ==================== 各类型回退实现 ====================

/**
 * 回退入库操作
 * 策略：扣减与入库等量的库存
 */
async function revertInbound(snapshot, operatorOpenId, remark) {
  const { target_doc_id, snapshot_data, operation_payload } = snapshot;
  const qtyToDeduct = operation_payload.quantity || 0;

  return await db.runTransaction(async transaction => {
    // 1. 读取当前产品
    const productRes = await transaction.collection('products').doc(target_doc_id).get();
    if (!productRes.data) throw new Error('产品不存在，无法回退');

    const currentStock = productRes.data.stock || 0;
    if (currentStock < qtyToDeduct) {
      throw new Error(`回退失败：当前库存(${currentStock})不足于抵消入库量(${qtyToDeduct})`);
    }

    // 2. 扣减库存
    await transaction.collection('products').doc(target_doc_id).update({
      data: { stock: _.inc(-qtyToDeduct) }
    });

    return { 
      deductedQty: qtyToDeduct, 
      message: `已抵消入库数量 ${qtyToDeduct}` 
    };
  });
}

/**
 * 回退出库操作
 * 策略：增加与出库等量的库存
 */
async function revertOutbound(snapshot, operatorOpenId, remark) {
  const { target_doc_id, operation_payload } = snapshot;
  const qtyToAdd = Math.abs(operation_payload.quantity) || 0;

  await db.collection('products').doc(target_doc_id).update({
    data: { stock: _.inc(qtyToAdd) }
  });

  return { 
    restoredQty: qtyToAdd, 
    message: `已恢复出库数量 ${qtyToAdd}` 
  };
}

/**
 * 回退产品编辑操作
 * 策略：用快照数据覆盖当前数据（选择性恢复关键字段）
 */
async function revertProductUpdate(snapshot, operatorOpenId, remark) {
  const { target_doc_id, snapshot_data } = snapshot;

  if (!snapshot_data) {
    throw new Error('快照数据不完整，无法回退');
  }

  // 构建恢复数据（从快照中提取核心字段）
  const restoreData = {};
  const RESTORABLE_FIELDS = [
    'oe_no', 'kyb_no', 'car_model', 'model_year', 'direction',
    'location', 'stock', 'price', 'brand', 'remark', 'warnStock',
    'images', 'status'
  ];

  for (const field of RESTORABLE_FIELDS) {
    if (snapshot_data.hasOwnProperty(field)) {
      restoreData[field] = snapshot_data[field];
    }
  }
  restoreData.update_time = db.serverDate();
  restoreData.last_reverted_at = db.serverDate();
  restoreData.last_reverted_by = operatorOpenId;

  await db.collection('products').doc(target_doc_id).update({
    data: restoreData
  });

  return { 
    restoredFields: Object.keys(restoreData), 
    message: `已恢复 ${Object.keys(restoreData).length} 个字段` 
  };
}

/**
 * 回退产品创建操作
 * 策略：标记删除（软删除），保留审计痕迹
 */
async function revertProductCreate(snapshot, operatorOpenId, remark) {
  const { target_doc_id } = snapshot;

  // 软删除：添加删除标记而非物理删除
  await db.collection('products').doc(target_doc_id).update({
    data: {
      status: 'deleted',
      deleted_at: db.serverDate(),
      deleted_by: operatorOpenId,
      delete_reason: `回退创建操作: ${remark.trim()}`
    }
  });

  // 同时将该产品的所有相关流水标记
  await db.collection('transaction_logs')
    .where({ product_id: target_doc_id })
    .update({
      data: { is_voided: true, void_reason: '关联产品已回退创建' }
    });

  return { 
    message: '产品已标记为删除，关联流水已作废' 
  };
}

async function getUserRole(openid) {

    .where({ _openid: openid })
    .limit(1)
    .get();
  if (res.data.length === 0) return null;
  return res.data[0].role || 'guest';
}
```

## 七、注意事项与风险提示

### ⚠️ 重要提醒
1. **库存回退时的边界条件**：回退入库时如果当前库存 < 原入库量，会拒绝回退（防止库存变负）
2. **并发安全**：回退操作使用了数据库事务，避免并发问题
3. **数据完整性**：回退本身也会产生一条 `type: 'undo'` 的流水记录，保证链路完整
4. **快照存储成本**：每次操作约增加 ~1KB 存储量，建议定期清理已回退/过期的快照（如90天前的 active 快照自动标记为 expired）
5. **产品创建回退采用软删除**：不会真正删除数据，只是标记 `status: 'deleted'`，可在控制台手动恢复

### 📊 存储估算
- 日均操作量：假设 500 次/天
- 单条快照大小：~1KB
- 月存储增量：~15MB
- 年存储增量：~180MB（云开发免费额度内可覆盖）
